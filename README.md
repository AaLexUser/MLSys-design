# SkillFactory

SkillFactory – агент, который помогает методологу создать проверенный навык для агента-ассистента. Код и промпты методолог при этом не пишет. Ассистент отвечает на вопросы сотрудников с помощью подключённых к нему инструментов: баз данных, внутренних API и других сервисов. Навык – файл `SKILL.md` с инструкцией, какие инструменты и данные использовать для класса задач и когда отказывать. К SkillFactory можно подключить любого ассистента.

## Какую задачу решает

Методолог знает бизнес-процесс, но не знает, какие инструменты, данные и права доступа есть у ассистента, и не умеет писать для него инструкции. Поэтому сейчас навыки пишет разработчик по описанию методолога. SkillFactory уточняет задачу вместе с методологом и через сессии самого ассистента выясняет его инструменты, данные и права. Затем агент ищет готовый навык в каталоге, пишет или дорабатывает навык и проверяет его в изолированной сессии ассистента. В каталог навык попадает только после одобрения методолога.

Итог сессии – один из пяти исходов.

| Исход | Что получает методолог |
| --- | --- |
| BLOCKED | Объяснение, каких данных, инструментов или прав не хватает |
| REUSE | Подтверждение, что готовый навык решает задачу |
| EXTEND | Проверенную доработку существующего навыка |
| CREATE | Проверенный новый навык |
| Черновик и отчёт "не готов" | Черновик и отчёт о сценариях, которые он не прошёл |

Качество измеряем на бенчмарке задач ассистента и сравниваем с бейзлайном, который генерирует навык за один вызов языковой модели. Целевая метрика – доля правильно решённых задач, защитные – корректность отказов, время и токены ассистента.

## Разработка

Нужны Python 3.11+ и [uv](https://docs.astral.sh/uv/).

```bash
uv sync
uv run pre-commit install
uv run pre-commit run --all-files
```

Pre-commit запускает ruff (линтер и форматер), pyrefly и базовые проверки файлов. Те же проверки идут в GitHub Actions на каждый push и pull request.
